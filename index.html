MIJN PRIORITEITEN

MoSCoW Methode

Met de MoSCoW-methode bepaal ik welke onderdelen belangrijk zijn voor mijn portfolio.

MUST HAVE

Moet erin

Een homepagina, informatie over mijzelf, projecten, navigatie en contactgegevens.

SHOULD HAVE

Belangrijk

Een overzicht van mijn vaardigheden, een goede indeling en een mobiele versie.

COULD HAVE

Extra's

Extra animaties, mooie afbeeldingen en verschillende hover-effecten.

WON'T HAVE

Niet nodig

Een ingewikkeld inlogsysteem of een uitgebreide database. Dit is niet nodig voor mijn portfolio.

VAN BEGIN TOT EINDE

Plan van Aanpak

Voor het maken van mijn portfolio gebruik ik de watervalmethode. Hierbij werk ik in verschillende fases. Eerst maak ik een ontwerp en daarna bouw ik de website.

Voorbereiding

Ik bekijk de opdracht en bepaal welke onderdelen mijn website moet hebben. Ik maak een planning en verzamel de benodigde informatie.

Ontwerp

Ik maak wireframes in Figma. Hierin bepaal ik waar de teksten, afbeeldingen, knoppen en navigatie komen.

Bouwen

Ik bouw mijn website met HTML, CSS en JavaScript. Ik voeg alle onderdelen, kleuren, afbeeldingen en animaties toe.

Testen

Ik controleer of de knoppen, links, afbeeldingen en animaties werken. Ook test ik mijn website op mobiel en desktop.

Afronden

Ik verwerk de laatste verbeteringen, controleer mijn code en maak mijn website klaar voor de eindpresentatie.

Applicaties die ik gebruik

Ik gebruik Visual Studio Code om te programmeren, Figma om mijn ontwerp te maken en een browser om mijn website te bekijken en te testen.
